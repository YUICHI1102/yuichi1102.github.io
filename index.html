Genji Uploader

Genji Uploader is a personal content-workflow tool operated by Yuichi Suzuki. It uses TikTok's official Content Posting API to upload videos prepared by the account owner to that owner's own TikTok inbox as drafts, so the owner can add music, write captions, and post them manually in the TikTok app.

The app never publishes content publicly, and it is used only with TikTok accounts owned or authorized by the operator.
